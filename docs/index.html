Goals and boundaries

Local first

Documents, Qdrant storage, embeddings, and responses stay on the developer machine when Ollama is selected.

Understandable

The RAG loop is plain Python: load, chunk, embed, retrieve, assemble context, generate. No hidden agent graph.

Replaceable edges

Small protocols isolate chat and embeddings. Each can use a different provider without changing ingestion or retrieval.

Portfolio ready

A web UI, OpenAPI endpoints, architecture notes, tests, CI, releases, and observable source scores demonstrate the whole system.

Not production SaaS

No accounts, tenancy, distributed workers, or cloud database. These only belong after usage creates a real need.

Zero required spend

Ollama, Qdrant local mode, Python libraries, GitHub Actions, and GitHub Pages are available without a paid runtime.

The FastAPI process owns orchestration. Ollama owns model inference. Qdrant runs in-process and persists beneath data/qdrant; no database server or Docker container is required.

Two explicit pipelines

Ingestion

  1. Validate file size and supported extension.
  2. Extract text from PDF, Markdown, or plain text.
  3. Preserve Markdown headings and split on natural boundaries with overlap.
  4. Embed chunks in batches with the configured embedding provider.
  5. Create or validate the Qdrant collection dimension.
  6. Replace stale chunks for the same filename and store citation metadata.

Question answering

  1. Embed the question with the same embedding provider.
  2. Fuse dense similarity with keyword coverage, optionally scoped to selected documents.
  3. Reject weak matches below RAG_SCORE_THRESHOLD.
  4. Build a bounded prompt containing labeled source excerpts.
  5. Ask the configured chat provider to answer only from that context.
  6. Return the answer plus structured citations and hybrid relevance scores.

Provider seams

Swappability is two structural typing contracts, not a dependency-injection framework. Configuration selects one implementation for each contract at startup.

class EmbeddingProvider(Protocol):
    async def embed(self, texts: list[str]) -> list[list[float]]: ...

class ChatProvider(Protocol):
    async def answer(self, question: str, context: str) -> str: ...

Default

RAG_EMBEDDING_PROVIDER=ollama
RAG_CHAT_PROVIDER=ollama
Uses independently configured models against the local Ollama base URL.

Optional

openai-compatible targets any compatible endpoint. Base URL, model, and API key are environment settings; neither OpenAI nor a paid account is required.

Data and retrieval model

Vector

The embedding is stored with cosine distance. Collection dimensionality is discovered from the first embedding and checked thereafter.

Payload

document_id, source, page, chunk_index, and text support citations, document filtering, deletion, and replacement on re-ingestion.

Chunking

PyMuPDF4LLM preserves PDF layout as Markdown; RapidOCR handles scanned pages locally; LangChain's standalone splitter preserves headings and natural text boundaries while enforcing configurable character limits.

Consistency rule

Changing the embedding model or provider requires rebuilding the collection. Mixing vector spaces produces invalid similarity results.

Runtime, privacy, and failure behavior

ConfigurationEnvironment variables with safe local defaults; .env is ignored and .env.example documents every setting.
Health/health reports application readiness and selected providers without exposing keys or document contents.
PrivacyLocal Ollama mode sends no document data to a third party. Selecting a remote compatible endpoint is an explicit operator decision.
Prompt safetyRetrieved documents are untrusted data. The system prompt tells the model to ignore instructions inside context and answer only from evidence.

Quality signalsThe UI reports elapsed work and citation scores; the live JSONL evaluator records retrieval, grounding, abstention, and p95 latency metrics.
BackupStop the app and copy data/qdrant. Source documents remain the canonical rebuild path.

Key decisions and upgrade triggers

Direct APIsKeep direct model APIs and use only LangChain's standalone text splitters; skip orchestration frameworks until they remove more code than they introduce.
Local QdrantSkip Docker and cloud storage. Move to Qdrant server when multiple processes, remote clients, or concurrent ingestion are required.
Structured chunksPreserve Markdown headings and natural text boundaries, then enforce configurable character limits with overlap.
Lightweight hybrid retrievalFuse dense similarity with keyword coverage. Add a local cross-encoder only if the evaluation set proves top-k precision is still insufficient.
No cloud IaCPulumi, AWS, and paid hosting conflict with the local zero-cost scope. The provider and vector-store seams preserve a migration path.
Golden evaluation datasetA checked-in schema and live runner score human-verified questions, expected evidence, required facts, abstention, and latency. Private cases and results remain outside Git.
