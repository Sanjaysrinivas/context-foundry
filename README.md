# Local RAG

An Ollama-first retrieval-augmented generation application that runs entirely on your machine. It keeps documents and vectors local, cites retrieved sources, and lets chat and embedding providers be configured independently.

> Development happens on `dev`. Feature branches start from `dev` and open pull requests back to `dev`; release pull requests promote `dev` to `main`.

The implementation and setup guide will land through focused feature branches. See the web architecture document at [`docs/architecture.html`](docs/architecture.html) once the architecture branch is merged.
